📘 Guide d'Utilisation (Module Test)

  1. Accéder à l'onglet 🧪 Test IA.
  2. Charger un fichier Excel via le sélecteur.
  3. Cliquer sur 🚀 Lancer l'Analyse.
  4. Le système effectue automatiquement :
    • Le nettoyage des données (valeurs manquantes, normalisation).
    • La sauvegarde sécurisée des données traitées (dossier processed).
    • L'exécution du modèle Isolation Forest.
  5. Consulter le tableau des anomalies détectées en bas de page.
