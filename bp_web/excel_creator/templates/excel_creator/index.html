  1. Accéder à l'onglet 🧪 Test IA.
  2. Charger un fichier Excel via le sélecteur.
  3. Cliquer sur 🚀 Lancer l'Analyse.
  4. Le système effectue automatiquement :
    • Le nettoyage des données (valeurs manquantes, normalisation).
    • La sauvegarde sécurisée des données traitées (dossier processed).

  5. Consulter le tableau des anomalies détectées en bas de page.

📘 Guide d'Utilisation Consolidation

▼

1. Sélection des Fichiers

Glissez-déposez vos fichiers Excel (.xlsx) dans la zone dédiée. Ils apparaîtront dans la liste.

2. Configuration

  • Auto Mode : Charge toutes les feuilles visibles.
  • Manuel Mode : Définissez précisément la feuille et les plages (ex: A1:F50).

3. Options de Sortie

Choisissez entre une consolidation simple (empilée), ou l'ajout de statistiques, graphiques et pages de synthèse.
